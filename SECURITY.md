# Security Policy

## Supported Versions

Only the latest released version of Drishti GEO is supported with security updates.

| Version | Supported |
| --- | --- |
| 2.0.x | :white_check_mark: |
| < 2.0 | :x: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately by emailing **miyanialkesh7@gmail.com** with:

- A description of the vulnerability and its impact
- Steps to reproduce
- Affected version(s)

You should receive an acknowledgement within 5 business days. Once a fix is confirmed, a new release will be published and the reporter credited (unless anonymity is requested).
